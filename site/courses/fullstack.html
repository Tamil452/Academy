What you will be able to do

  • Build responsive pages with HTML, CSS and modern JavaScript
  • Create interactive interfaces in React
  • Write REST APIs with Node.js and Express
  • Design and query SQL and MongoDB databases
  • Use Git and GitHub the way teams do
  • Deploy an application to the cloud

Who this course is for

  • Graduates who want a first job in software
  • Working professionals moving into tech
  • Self-taught learners who want structure and feedback

Before you start

No coding experience needed. You should be comfortable using a computer and typing.

Syllabus

1Web foundationsWeeks 1–4
  • How the web works
  • Semantic HTML
  • CSS layout with flexbox and grid
  • Responsive design
2JavaScriptWeeks 5–9
  • Variables, functions and objects
  • DOM and events
  • Async code and fetch
  • Debugging in the browser
3ReactWeeks 10–14
  • Components and props
  • State and hooks
  • Routing
  • Working with APIs
4Back end with Node.jsWeeks 15–19
  • Express and REST
  • Authentication
  • SQL and MongoDB
  • Testing APIs
5ShippingWeeks 20–24
  • Git workflows
  • Deployment
  • Capstone project
  • Demo day

What you will build

Each project is reviewed by your instructor and goes into your portfolio.

Portfolio website

A responsive personal site you deploy in month two and keep improving.

Task manager app

A React app with login, saved data and a REST API you write yourself.

Capstone

A full-stack product you choose, built in a team and presented on demo day.

Tools you will use

  • VS Code
  • Git and GitHub
  • React
  • Node.js
  • Express
  • PostgreSQL
  • MongoDB
  • Postman
