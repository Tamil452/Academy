What you will be able to do

  • Clean and organise data in Excel
  • Write SQL queries to pull and join data
  • Analyse data with Python and pandas
  • Build interactive Power BI dashboards
  • Pick the right chart for the question
  • Present findings to non-technical people

Who this course is for

  • Graduates from any stream with an interest in numbers
  • Professionals in finance, sales or operations
  • Anyone who works with spreadsheets every day

Before you start

Basic school maths and some familiarity with Excel. No programming needed.

Syllabus

1Excel for analysisWeeks 1–3
  • Formulas and lookups
  • Pivot tables
  • Cleaning data
  • Charts
2SQLWeeks 4–6
  • SELECT and filtering
  • Joins
  • Grouping and aggregation
  • Window functions
3Python for dataWeeks 7–11
  • Python basics
  • pandas
  • Exploratory analysis
  • matplotlib and seaborn
4Power BIWeeks 12–15
  • Data modelling
  • DAX measures
  • Dashboard design
  • Publishing and sharing
5CapstoneWeeks 16–17
  • Choose a dataset
  • Analysis
  • Dashboard
  • Final presentation

What you will build

Each project is reviewed by your instructor and goes into your portfolio.

Sales performance report

An Excel and SQL analysis of a retail dataset with clear recommendations.

Customer insights notebook

A Python analysis that segments customers and explains what drives repeat purchases.

Executive dashboard

A Power BI dashboard built for a manager who has five minutes to read it.

Tools you will use

  • Excel
  • MySQL
  • Python
  • pandas
  • Jupyter
  • Power BI
